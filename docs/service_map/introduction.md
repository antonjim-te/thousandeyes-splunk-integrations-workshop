You can run the Service Map integration in two ways, depending on your environment and preference:

### Run on an AWS EC2 instance

If you can use AWS cloud-hosted setup, use the AWS EC2 path.

- Start here: [Advanced Integration (using AWS) — Getting Started](advanced_aws/getting_started.md)

### Run locally on your machine

If you prefer to run everything locally on your laptop/workstation. This approach is great for fast iteration and when you do not need cloud infrastructure.

- Start here: [Advanced Integration (running locally) — Getting Started](advanced_locally/getting_started.md)
